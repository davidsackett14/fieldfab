# FieldFab

An installable HVAC fabrication PWA for iPhone and Chromebook.

## Current features

- Imperial and metric project settings
- Imperial fractional input
- Selectable display/fabrication tolerance
- Top and bottom transition dimensions
- Center offsets in both axes
- Four independent vertical corner heights
- Live calculated corner-edge lengths
- Rotatable and zoomable 3D fitting
- Local project-state persistence
- Offline application shell

## Run locally

Serve the repository using any static HTTP server. ES modules and the service worker will not run correctly by opening `index.html` directly from the filesystem.

## Deployment

The repository is designed for GitHub Pages deployment from the `main` branch root.
